# 📊 Debraj's E-Commerce Sales Analysis Dashboard

An interactive **Power BI dashboard** designed to analyze and visualize E-Commerce sales data.  
The project transforms raw transactional data into meaningful insights that help understand sales performance, profit trends, and customer behavior.

---

## 🚀 Project Overview

This dashboard provides a complete analysis of an E-Commerce dataset including:

- Sales performance
- Profit trends
- Product category performance
- Regional sales distribution
- Customer payment preferences

The dashboard helps businesses make **data-driven decisions** by identifying profitable segments and performance trends.

---

## 🎯 Objectives

The main goals of this project are:

- Analyze overall **sales and profit performance**
- Identify **top-performing product categories**
- Study **monthly profit trends**
- Understand **state-wise sales distribution**
- Analyze **customer payment methods**
- Detect patterns in product demand

---

## 📊 Key Metrics

The dashboard highlights important KPIs including:

- **Total Sales Amount**
- **Total Quantity Sold**
- **Total Profit**
- **Average Order Value (AOV)**

These KPIs provide a quick overview of business performance.

---

## 📈 Dashboard Features

### 1️⃣ Sales by State
Displays the total sales generated from different states.

### 2️⃣ Monthly Profit Analysis
Shows profit trends across months to identify seasonal patterns.

### 3️⃣ Quantity by Category
Analyzes the number of products sold across different categories.

### 4️⃣ Payment Mode Distribution
Shows how customers prefer to pay using:
- COD
- UPI
- EMI
- Debit Card

### 5️⃣ Profit by Sub-Category
Identifies which product sub-categories contribute most to profit.

---

## 🎛 Interactive Filters

The dashboard includes dynamic filters that allow users to explore the data:

- **State Filter**
- **Quarter Filter**
- **Profit Category Filter**

These filters help users drill down into specific segments of the data.
